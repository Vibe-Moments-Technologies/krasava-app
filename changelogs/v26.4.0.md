# 📱 Красава! v26.4.0

> **Дата релиза:** не выпущен (стадия: beta.2 + dev-сборки) · **Линия:** `26.4.0`
> **Файл живёт в** [`changelogs/`](./) — глобальный журнал: [`CHANGELOG.md`](../CHANGELOG.md)

178 коммитов с v26.3.0 — самый большой релиз в истории приложения.

## ✨ Новое

### 🎮 Игры
- **Раздел «Игры»** — Сапёр и Тетрис прямо в приложении, без интернета.
- **«Сапёр»**: восемь режимов (9×9 … большие поля), рекорды на каждый режим, зум и защита от случайных тапов.
- **«Тетрис»**: настройки управления (кнопки/свайпы), три уровня сложности, рекорды.
- **Тема Error** — глобальная тема в стиле «синего экрана»: скан-линии, глитч-надписи. Даётся за режим Сапёра, решённый с одного тапа; тумблер «Починить ошибку» в отладке.

### 📅 iOS-виджеты расписания
- **Четыре размера** (Small / Medium / Large / Extra Large для iPad) по фирменному ТЗ — с движком выбора пары, 25 unit-тестов.
- Снапшот расписания в App Group — виджет работает без запуска приложения, синхронизация при появлении/в фоне/возврате.
- **App Group определяется в рантайме из профиля переподписи** — совместим с GBox/SideStore/Scarlet и любым инструментом переподписи.
- Выбор группы в настройках виджета; диагностика пустого состояния («нет App Group в подписи» / «нет данных» / «битые данные»).

### 🤖 Android-виджеты (Glance)
- Виджет расписания на Glance с конфигуратором («По умолчанию» / выбор группы, сокращение названий).
- Добавление виджета прямо из настроек приложения; цвета из активной темы; живой статус прав.

### 🎨 Темы
- **«Кавай»** — новая пастельная палитра, отдельная от «Сакуры»; подстраница «Тематические темы».
- **Хэллоуинская тема** — сезон 28 октября – 3 ноября включительно, только тёмная, перекрывает любые темы; вне сезона включается вручную (для квеста).
- Развёл «Кавай» и «Киберпанк»: у каждой свой характер; вариант палитры Киберпанка (NEON/CLASSIC) в настройках.
- Цвета типов занятий для приложения и виджета.

### 🔔 Расписание и уведомления
- **Календарь раскрытием свайпом**: неделя → две недели → месяц (жест по всей ленте, issue #3).
- **Новые типы занятий**: экзамен (ЭКЗ), зачёт (ЗАЧ), курсовая (КР), консультация (КОНС), самостоятельная работа (СР), мероприятие (МР) — свои бейджи и цвета; приоритет — полному названию из фида (филиальные аббревиатуры распознаются).
- **Цвета занятий** в настройках: акцент для каждого типа, можно задать заранее — новый тип не «занял» чужой цвет.
- **Новый формат уведомлений**: заголовок «Через N мин», тело — предмет в ЧЧ:ММ, ауд. X; тестовые уведомления из отладки — вид как у боевых.
- **Новая съёмка МП-1** в картах — по умолчанию; старая возвращается тумблером в отладке.
- **Месячный календарь** (оверлей): «Сегодня» — пилюля в шапке справа от «Месяц Год» (только если день ≠ сегодня), «Отмена» убрана, карточка крупнее, легенда показывает только типы активного расписания.

### 🩺 Диагностика и приватность
- **Sentry вместо AppMetrica**: отправка только по желанию — тумблер в скрытом меню отладки (по умолчанию выключен); на dev/beta/contrib включён всегда. CI грузит dSYM.
- **Экран отладки по секциям**: режимы / диагностика / хранилище / уведомления / эксперименты / сброс; скролл переживает переходы; карточка «Сведения о приложении» (bundle id, App Group контейнеры).
- **Юрдокументы на gh-pages**: terms.html + privacy.html — обновляются без релиза приложения.

## 🐛 Исправления

- Заметки: файл в documents — переживают сброс и очистку кеша; ремап при сдвиге/переносе пары; синхронная запись («закрыл шит = записано»); нативное скрытие клавиатуры и перехват Done на iOS; iOS-запись молча проваливалась (moveItemAtPath не перезаписывает).
- Тумблер напоминаний не врёт (конфигуратор виджета — при добавлении из приложения).
- Кеш NSURLSession держал старый JSON тестового фида 5 минут — Cache-Control: no-cache.
- СДО — дистанционная пара, не корпус; сокращение — по правилу приложения.
- Список групп ровно по ширине капсулы, скруглённые уголки DropdownMenu.
- Android: Sentry auto-init валил запуск — выключен; ACCESS_NETWORK_STATE для VPN-детектора.
- API: проверка HTTP-статуса — мёртвый прокси не затирает кеш пустым расписанием; свободные аудитории не публикуют частичные данные.
- iOS: свайп системной шорки больше не двигает расписание; isAuthorized без async; ad-hoc codesign с entitlements перед упаковкой IPA.
- Виджеты: один виджет в галерее, 6 пар в Large, аудитория не выдавливается за край, шапка не режется, выбор группы и сокращённые названия.
- Тетрис: пол скорости 80 мс сходился со своим же тестом.
- Календарь: месяц в заголовке — от выбранного дня (граничные недели типа 27 окт–1 ноя); срез префикса типа из названия предмета.
- Отзывы по навигации: единый currentTab без кадра-вспышки, шестерёнка с окантовкой, «назад» на карте из блока сервисов.
