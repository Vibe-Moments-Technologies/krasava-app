# 📱 Красава! v26.4.0

> **Дата релиза:** 6 ноября 2026 · **Релиз:** [`v26.4.0`](https://github.com/Vibe-Moments-Technologies/krasava-app/releases/tag/v26.4.0)
> **Подробные списки изменений всех версий:** [`changelogs/`](./) · общий журнал: [`CHANGELOG.md`](../CHANGELOG.md)

178 коммитов с v26.3.0 — самый большой релиз в истории приложения.

## ✨ Новое

### 🎮 Игры
- Новый раздел «Игры»: «Сапёр» и «Тетрис» работают прямо в приложении, без интернета.
- «Сапёр»: восемь размеров поля — от классического 9×9 до больших; для каждого режима свой рекорд; зум и защита от случайных тапов.
- «Тетрис»: кнопки или свайпы — на выбор, три уровня сложности, рекорды.
- Тема Error — глобальная тема в духе «синего экрана»: скан-линии и глючащие надписи. Выдаётся за партию в «Сапёре», решённую с первого тапа; вернуть обычный вид можно кнопкой «Починить ошибку» в меню отладки.

### 📅 Виджеты расписания (iPhone и iPad)
- Четыре размера: маленький, средний, большой и очень большой (для iPad).
- Виджет сам выбирает, какую пару показать — текущую или следующую, — и работает без запуска приложения: расписание синхронизируется в фоне.
- Виджет работает при установке через GBox, SideStore, Scarlet и другие альтернативные клиенты: нужное хранилище данных определяется прямо из профиля установки.
- В настройках виджета можно выбрать группу. Если данных нет, виджет честно объясняет, почему: нет подписи, нет данных или данные повреждены.

### 🤖 Виджеты расписания (Android)
- Виджет расписания с настройками: расписание «по умолчанию» или выбранная группа, сокращённые названия предметов.
- Виджет можно добавить прямо из настроек приложения; он подхватывает цвета активной темы и показывает текущее состояние разрешений.

### 🎨 Темы
- Новая тема «Кавай» — мягкая пастельная палитра. Все особые темы собраны на подстранице «Тематические темы».
- Хэллоуинская тема: сама включается с 28 октября по 3 ноября, работает только в тёмном виде и на это время перекрывает любые другие темы. Вне сезона её можно включить вручную — это награда за квест.
- Темы «Кавай» и «Киберпанк» переработаны, чтобы их нельзя было спутать: у каждой свой характер. Для «Киберпанка» в настройках появился выбор варианта палитры — NEON или CLASSIC.
- Цвета типов занятий — и в приложении, и в виджетах.

### 🔔 Расписание и уведомления
- Календарь раскрывается свайпом: неделя → две недели → месяц. Жест работает по всей ленте календаря.
- Новые типы занятий: экзамен, зачёт, курсовая, консультация, самостоятельная работа и мероприятие. У каждого свой бейдж и цвет; тип определяется по полному названию из расписания, филиальные аббревиатуры распознаются правильно.
- Новый раздел настроек «Цвета занятий»: акцентный цвет для каждого типа. Цвет можно задать заранее — если в расписании появится новый тип, он не займёт чужой цвет.
- Новый формат напоминаний: заголовок «Через N мин», в теле — предмет, время и аудитория. Тестовые напоминания из меню отладки выглядят в точности как настоящие.
- Новая съёмка МП-1 на картах — теперь по умолчанию; прежняя схема доступна через тумблер в отладке.
- Месячный календарь переработан: кнопка «Сегодня» переехала в шапку рядом с «Месяц Год» и видна, только если выбран не сегодняшний день; лишняя «Отмена» убрана; сам календарь стал крупнее; легенда типов показывает только те, что есть в текущем расписании.

### 🩺 Диагностика и приватность
- Вместо AppMetrica теперь Sentry: отчёты о сбоях отправляются только с вашего согласия — тумблер в скрытом меню отладки, по умолчанию выключен. На тестовых сборках отправка включена всегда.
- Меню отладки переработано на разделы: режимы, диагностика, хранилище, уведомления, эксперименты и сброс. Карточка «Сведения о приложении» показывает идентификатор приложения и состояние хранилища для виджетов.
- Пользовательское соглашение и политика конфиденциальности переехали на страницу проекта — их можно обновлять без выпуска новой версии приложения.

### 🔄 Обновления
- Диалог «Вышла новая версия»: галочка «Не показывать для этой версии», пометка, что прямая сборка уже доступна на GitHub, сброс подавления в отладке. Тап по красному мини-виджету версии открывает предупреждение.
- Тестовый источник версий (только на тестовых сборках) — чтобы проверять поведение приложения при разных версиях.
- Список изменений каждой версии теперь живёт отдельным файлом, а в источнике обновлений лежит ссылка на него: в диалоге появилась кнопка «Полный список изменений».

### 🧭 Интерфейс
- Панель навигации можно скрыть (тумблер в «Интерфейс и навигация»): «Другое» тогда открывается шестерёнкой на странице расписания, а все сервисы становятся блоками внутри него.
- Все белые надписи приложения получили фирменный эффект мерцания со скан-бликами.

## 🐛 Исправления

- Заметки: хранятся отдельным файлом и не пропадают при сбросе приложения и очистке кеша; корректно переносятся при сдвиге пары на другое время или день; сохраняются сразу при закрытии окна; на iPhone починена клавиатура и редкая ошибка, когда заметка молча не сохранялась.
- Тумблер напоминаний всегда показывает реальное разрешение на уведомления; при добавлении виджета из приложения сразу открываются его настройки.
- Проверка обновлений больше не застревает на устаревшем кеше.
- Пары с аудиторией «СДО» считаются дистанционными, а не корпусом.
- Список выбора групп выровнен по ширине капсулы, у выпадающих меню скруглены уголки.
- Android: исправлено падение на запуске (Sentry), предупреждение о VPN снова работает.
- При сбое сети сохранённое расписание больше не затирается пустым, а «Свободные аудитории» не показывают неполные данные.
- iPhone: свайп системной шторки больше не двигает расписание.
- Виджеты: в галерее нет дубликатов; в большом размере видно до шести пар; текст не выдавливается за края и не обрезается.
- Заголовок календаря показывает месяц выбранного дня, а не понедельника недели; из названий предметов убран дублирующий префикс типа («ЛК Математика» → «Математика»).
- Переходы между разделами плавные, без кадра-вспышки; шестерёнка оформлена в общем стиле; со страницы карты работает «назад» из блока сервисов.
