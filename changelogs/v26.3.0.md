## ✨ Новое

### 🏷️ Ребрендинг
- Приложение теперь называется **«Красава!»** и переехало в организацию **Vibe Moments Technologies**.
- Новый безопасный ключ подписи.

### 📚 Ресурсы
- **Раздел «Ресурсы»**: сервисы университета, сообщества институтов и студенческих организаций — в одном месте, с папками и переходами как во всём приложении.
- Ссылки на соцсети обновляются без обновления приложения.

### 📝 Заметки к парам
- Пишите заметки прямо на странице занятия — заметка видна в карточке расписания и удаляется вместе с ним.
- Панель инструментов на странице пары: заметки и добавление предмета в задачи.

### ⚙️ Настройки
- Настройки сгруппированы по разделам: отображение расписания, прогресс, календарь, параметры сервисов.

### 📅 Расписание
- ДОП-пары: розовый бейдж и тумблер «Скрывать доп. занятия».

### 🔄 Обновления
- Обновления через магазин: проверка версии стала информационной (маркеты обновляют сами).

### 🩺 Аналитика
- Диагностика сбоев обязательна, события использования — по согласию; новый экран приветствия.

### ℹ️ О программе
- Команда с контактами, блок «Контакты»; новые иконки.

## 🐛 Исправления

- Мелкие исправления стабильности.
