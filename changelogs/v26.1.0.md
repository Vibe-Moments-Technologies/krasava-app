## ✨ Новое

### 🔀 Сравнение расписаний
- Две и более групп рядом на одном экране, подсветка различий, поиск по сохранённым целям.

### 📊 Статистика
- При первом входе приложение спрашивает согласие на анонимную статистику падений и использования разделов (включается/отключается в настройках).

### 🚀 Запуск
- Больше нет белой вспышки при запуске в тёмной теме.

### 🧭 Панель вкладок
- Новый состав по умолчанию: Расписание, Задачи, Карта, Другое; вкладки по-прежнему настраиваются.
